# CoinNest — Brand & Rewards Engagement Platform (Prototype)

A premium rewards platform connecting brands and users in India. This repository contains a front-end UI/UX prototype (mock data only) for the CoinNest app: user rewards app and admin panel.

Status: UI/UX prototype (front-end only, mock data). No backend, database, or auth is wired up yet.

Getting started (dev):

1. Clone this repo
2. cd coinnest
3. npm install
4. npm start

Note: Tailwind CSS build step or CDN is required for the Tailwind utility classes used in components.

Roadmap and architecture notes in docs/architecture.md
